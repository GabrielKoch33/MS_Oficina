# 🚀 Landing Page Institucional

Este projeto consiste em uma landing page desenvolvida para a empresa do meu pai. O site foi construído como parte de um trabalho acadêmico da faculdade, aplicando conceitos fundamentais de desenvolvimento web frontend.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica do projeto.
* **CSS3:** Estilização, layout e responsividade.
* **JavaScript:** Interatividade e dinamicidade da página.

## 🎯 Objetivos do Projeto
- Aplicar na prática os conceitos aprendidos no curso.
- Criar uma identidade do produto usando cores e imagens que referênciem a empresa.
